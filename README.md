# Mealify 🍽️

Mealify is a responsive restaurant landing page built using HTML and CSS.  
The website showcases a modern layout for a restaurant, allowing visitors to explore chefs, view food images, and contact the restaurant easily.

## 🚀 Features
- Responsive design
- Modern restaurant landing page layout

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome

## 📂 Project Structure
```
Mealify/
│
├── index.html
├── css/
│   └── style.css
├── images/
│   └── (project images)
└── README.md
```

## 🎯 Purpose
This project was created to practice building responsive landing pages using HTML and CSS and to improve front-end development skills.
